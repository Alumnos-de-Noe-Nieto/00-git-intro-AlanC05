## ¿Qué es Git?

Git es un sistema de control de versiones que permite a los programadores
Poder ver los cambios que se realizaron
Poder revertir los cambios en caso de que haya sucedido algún error
Trabajar con varios compañeros

## Por qué necesitamos Git

Sin Git, cuando trabajamos en equipo...
Trabajar en equipo
Editar todos los archivos sin interrumpir a los compañeros

## Los 3 conceptos clave de Git

1. **Repositorio:** Una carpeta especial
2. **Commit:** Punto de guardado del código
3. **Rama:** Una parte del trabajo separado del trabajo principal, de manera que cada quien puede trabajar por separado y después juntar todo

## Los comandos que aprendí
git push para subir cambios a github
git pull para descargar cambios de github
git remote add para conectar el local con github
git commit para guardar los cambios con un mensaje
git init para inicializar git
git push para para subir el contenido cambiado a github

## Mi reflexión final

Lo más importante que aprendí de Git es...
Porque te permite trabajar en tiempo real con tus compañeros
Te permite revisar en todo momento quién editó tal parte del código
